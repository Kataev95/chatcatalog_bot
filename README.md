# 🗂 Каталог чатов — Telegram-бот на Rich Messages

Бот-каталог групп и каналов. Сообщения свёрстаны новыми **Rich Messages** (Bot API 10.1–10.3):
заголовки, таблицы, раскрывающиеся блоки, кнопки «Вступить» и «Скопировать» прямо внутри сообщения,
цветные инлайн-кнопки (`style`: success / danger / primary). Если клиент или API не принял rich-сообщение,
бот сам отправит обычный HTML.

## Что умеет
**Пользователи**
- 💬 Все чаты одним списком (новые сверху) и 🔥 Топ по участникам, таблица с возрастом и пагинацией
- 🔥 Топ, 🔍 поиск (просто напиши слово), инлайн-поиск `@бот запрос` в любом чате
- ➕ Добавить свой чат: ссылкой, `@username`, инвайтом `t.me/+…` или системной кнопкой «Выбрать мой чат»
- Название, описание, число участников и **аватарку** бот подтягивает сам; можно прислать свою обложку. Заявка уходит на модерацию
- 🖼 Фото в карточке чата и коллаж аватарок над списком (rich-блоки `<figure>` и `<tg-collage>`)

**Админ** (`/admin`)
- Модерация очередью: ✅ одобрить / ❌ отклонить / ✏️ переименовать / 🖼 сменить обложку, автору приходит уведомление
- Добавление без модерации, удаление (кнопка 🗑 в карточке или `/del 15`, `/del @username`)
- 📨 Пересланный пост про один чат (картинка + название + ссылка + описание + «Возраст: 18+» + #теги) сразу становится карточкой с картинкой. Повторная пересылка обновляет карточку
- 🖼 Обложка: кнопка в карточке (фото или «-» для возврата аватарки), `/avatars` подтягивает аватарки старым записям
- **Массовый импорт**, три способа:
  1. **Перешли боту посты** из канала-подборки: он вытащит все ссылки, включая скрытые под текстом
  2. `/import` или `/import Крипта`, затем вставь текст или пришли `.txt`
  3. **Автоимпорт**: сделай бота админом канала-источника и впиши его в `SOURCE_CHANNELS`, новые посты будут разбираться сами
- **Вся история канала сразу**: `export_channel.py` (Telethon, через твой аккаунт) собирает ссылки из всех старых постов в `links.txt`, его отправляешь боту после `/import`

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env      # BOT_TOKEN и свой ID в ADMINS
python bot.py
```
В @BotFather: `/setinline` (для инлайн-поиска) и `/setjoingroups` по желанию.

## Ограничения Telegram, о которых стоит знать
- Приватные инвайты `t.me/+…` бот проверить не может: название берётся из подписи в посте
- Проверка username (`getChat`) ограничена по частоте, поэтому импорт идёт примерно 2 ссылки в секунду, в фоне
- Аватарка загружается в Telegram один раз, дальше переиспользуется по file_id
- Rich Messages нужны свежие клиенты Telegram; у старых бот уходит в обычный HTML

## Файлы
| Файл | Что внутри |
|---|---|
| bot.py | хендлеры, меню, модерация, импорт, инлайн |
| views.py | вёрстка rich-сообщений и клавиатур |
| tgrich.py | клиент sendRichMessage + запасной HTML |
| linkparser.py | извлечение ссылок из постов (t.me, @, text_link) |
| importer.py | проверка через getChat и запись в базу |
| db.py | SQLite: chats, categories, users |
| export_channel.py | выгрузка ссылок из истории канала (Telethon) |
